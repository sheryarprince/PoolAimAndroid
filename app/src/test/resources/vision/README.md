# Initial 8 Ball Pool recognition set

Seven recovered gameplay screenshots form the first manually annotated corpus. The JSON stores original pixel coordinates and radii. IDs follow the original trainer convention (0 cue, 1–7 solids, 8 eight ball, 9–15 stripes). Unknown IDs remain null when a number is obscured or unreadable.

The JPGs are supplied in the separate PoolAim_8BallPool_Screenshot_Corpus.zip. Overlay-heavy screenshots should be scored separately from clean gameplay captures.
